# Architecture decision records

One file per decision, `NNNN-slug.md`, numbered in creation order and never renumbered. Use
[ADR.md](../../spec/templates/ADR.md).

Classify every ADR as owner requirement, roadmap default, measured implementation choice, or
unresolved owner gate. A superseded ADR stays in place with a `superseded by` link; it is not
deleted. An exception ADR names its expiry milestone and removal gate.
