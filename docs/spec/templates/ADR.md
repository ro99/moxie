## Problem and mechanism

Source/commit, observed behavior, relevant requirement and why the current contract is insufficient.

## Options examined

For each: semantic correctness, memory peak, prefill and decode, actual context, precision/quality, hardware support, complexity/reuse, licensing and migration/deletion cost. Cite pinned upstream code where used. Distinguish measured facts from estimates.

## Decision and authority

Exact contract selected; who can approve it; resolved owner gate if applicable. No silent change to precision, cache policy, concurrency or product scope.

## Evidence and acceptance

Oracle, numerical criteria, test/result IDs, resource accounting, affected consumers, rejected alternatives and limitations.

## Enforcement and removal

Machine checks, compatibility behavior, old path removed, temporary exception expiry, rollback plan and re-evaluation trigger.
